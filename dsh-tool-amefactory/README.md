# dsh-tool-amefactory

AI Multi-modal Content Factory - Content briefs, image prompts, video scripts, social media optimization, SEO scoring, brand voice analysis, content calendars, and repurposing engine

## Tools

- content_brief_generator
- image_prompt_engine
- video_script_writer
- social_media_optimizer
- seo_content_scorer
- brand_voice_analyzer
- content_calendar_planner
- repurposing_engine

## Install

```bash
npm install
npm run build
```
