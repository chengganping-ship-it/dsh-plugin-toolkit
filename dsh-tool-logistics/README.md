# dsh-tool-logistics

Logistics & Route Optimization Engine - Route optimization, warehouse allocation, last-mile delivery planning, freight cost analysis, inventory positioning, cross-dock scheduling, fleet utilization tracking, and carbon logistics emissions calculator

## Tools

- route_optimizer
- warehouse_optimizer
- last_mile_planner
- freight_cost_analyzer
- inventory_positioning
- cross_dock_scheduler
- fleet_utilization_tracker
- carbon_logistics_calculator

## Install

```bash
npm install
npm run build
```
