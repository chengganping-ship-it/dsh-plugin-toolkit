# dsh-tool-testengineer

AI Testing Engineer plugin for DeepSeek Harness (DSH). Provides comprehensive agent testing, evaluation, reliability scoring, and bias detection capabilities.

## Tools

| Tool | Description |
|------|-------------|
| `agent_test_designer` | Design test cases for AI agents based on capabilities and scenarios |
| `evaluation_framework` | Build complete evaluation frameworks with quality dimensions and metrics |
| `reliability_scorer` | Score agent output consistency and generate reliability reports |
| `bias_detector` | Detect bias in agent responses across sensitive attributes |
| `regression_analyzer` | Analyze performance changes and detect degradation over time |
| `capability_benchmark` | Benchmark agent capabilities against reference models |
| `stress_test_designer` | Design stress tests to validate agent limits and failure modes |
| `test_report_generator` | Generate comprehensive test reports with coverage analysis |

## Installation

```bash
npm install
```

## Build

```bash
npm run build
```

## Usage

```typescript
import {
  agent_test_designer,
  evaluation_framework,
  reliability_scorer,
  bias_detector,
  regression_analyzer,
  capability_benchmark,
  stress_test_designer,
  test_report_generator
} from 'dsh-tool-testengineer';
```
