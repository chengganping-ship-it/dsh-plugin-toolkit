# ATS Keyword Checklist
*The definitive checklist to make sure your resume passes Applicant Tracking Systems and reaches a human.*

---

## What ATS actually does (30 seconds of truth)

ATS software scans your resume for keywords from the job description, checks formatting, and ranks you against other applicants. **If your resume can't be parsed, you're filtered out before a human ever sees it.** This checklist fixes both problems.

---

## Part A — Keyword Match (the highest-impact fixes)

- [ ] I extracted the exact keywords from the job posting (tools, software, certifications, hard skills)
- [ ] I used the SAME exact terms as the JD, not synonyms
  - Bad: "worked with clients" when JD says "customer success"
  - Good: use "customer success" verbatim
- [ ] My target keywords appear in the Professional Summary
- [ ] My target keywords appear in a "Core Competencies" / "Skills" section
- [ ] My top 2-3 keywords also appear naturally in work-experience bullets (not just listed)
- [ ] I did NOT keyword-stuff (repeating the same word unnaturally) — ATS can flag it
- [ ] Acronyms are spelled out once: "SEO (Search Engine Optimization)" then "SEO"

---

## Part B — Formatting (what gets you auto-rejected)

- [ ] File is .docx or .pdf (NOT .png, .jpeg, .pages, or a photo of a resume)
- [ ] Standard section headers: "Professional Summary", "Work Experience", "Education", "Skills"
- [ ] NO tables, text boxes, columns, or graphics — ATS reads left-to-right, top-to-bottom only
- [ ] NO headers/footers with critical info (some ATS can't read them)
- [ ] Standard fonts (Arial, Calibri, Times New Roman) size 10-12 — no decorative fonts
- [ ] NO images, logos, icons, or photos in the body
- [ ] Dates formatted consistently: "Jan 2021 – Mar 2023" or "2021–2023", pick one
- [ ] NO special characters in section headings (avoid "★", "✎", symbols)
- [ ] Single-column layout
- [ ] Links (LinkedIn, portfolio) are full URLs, not hyperlinked words

---

## Part C — Content Signals

- [ ] Contact info at top: name, email, phone, city/state, LinkedIn URL
- [ ] Bullet points start with action verbs
- [ ] Quantified results (numbers, %, $, time) in as many bullets as possible
- [ ] No obvious typos or inconsistent spacing
- [ ] Job titles match what the market uses (not internal-only titles)
- [ ] I've run my final version through a free ATS check tool (Jobscan, Resume Worded, or similar)

---

## The "one-paste" AI verification prompt

```
Act as an ATS recruiter. Review this resume against this job description. Score the keyword match /100. List:
1. Keywords I'm missing (must-have first)
2. Any formatting that would cause ATS parsing failure
3. The single highest-impact change I should make
Resume: <paste>
Job Description: <paste>
```

## Pro tip

Apply for the "stretch" role? Don't copy-paste the same resume. Re-run the keyword step for each new JD. Tailoring 20 minutes per application beats blasting 50 identical resumes.
