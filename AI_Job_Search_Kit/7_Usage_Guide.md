# Usage Guide
*How to use the AI Job Search Kit — start here. 5 minutes to set up, then run it as fast or as deep as you like.*

---

## What's in this kit

| File | What it does |
|---|---|
| 1_Resume_Rewrite_Prompt.md | Rewrites your resume to beat ATS + impress recruiters |
| 2_Cover_Letter_Generator.md | Writes tailored, non-templated cover letters |
| 3_LinkedIn_Profile_Template.md | Optimizes your headline, About, and experience for recruiter search |
| 4_Interview_QA_Generator.md | Builds a targeted interview prep packet from the job posting |
| 5_ATS_Keyword_Checklist.md | The exact checklist to pass automated screens |
| 6_Job_Application_Tracker.md | Tracks applications + follow-ups so nothing slips |

---

## Before you start (5 minutes)

1. Open any AI chat tool (ChatGPT, Claude, Gemini — all work).
2. Have your **current resume** and your **target job posting** ready as copy-paste text.
3. Decide ONE target role to optimize for first. Focus beats spreading thin.

---

## Recommended order (for a first-time user)

1. **Run 5_ATS_Keyword_Checklist** once to see where you stand. It tells you the highest-impact fix.
2. **Run 1_Resume_Rewrite_Prompt** with your resume + one target JD. Get your ATS-optimized version.
3. **Run 3_LinkedIn_Profile_Template** to fix your profile (recruiters find you here before you apply).
4. **Run 2_Cover_Letter_Generator** for each specific application (never a generic letter).
5. **Run 4_Interview_QA_Generator** the day before each interview.
6. **Set up 6_Job_Application_Tracker** and log every application from day one.

---

## The 7-day fast track (if you're in a hurry)

- **Day 1:** Resume rewrite (file 1) + ATS check (file 5). ~1 hour.
- **Day 2:** LinkedIn optimization (file 3). ~1 hour.
- **Day 3:** Apply to 3 target roles with tailored cover letters (file 2). ~1.5 hours.
- **Day 4:** Set up tracker (file 6), follow up on Day-1 applications. ~30 min.
- **Day 5:** Interview prep for any callbacks (file 4). ~1 hour.
- **Day 6:** Apply to 3 more roles, refine based on what's working.
- **Day 7:** Review your tracker: which source converts best? Double down on it.

---

## Golden rules

1. **Never let AI invent facts.** Use `[brackets]` for real numbers you need to fill in.
2. **Tailor per application.** 20 good applications beat 50 blasts.
3. **Follow up.** Most candidates lose opportunities by never sending Day-3 follow-ups.
4. **AI is your copywriter, not your brain.** You still make the decisions.

---

## Troubleshooting

**The resume looks generic?** Re-run with the "Too generic?" tweak from file 1, and paste more specific context about your actual work.

**Not getting interviews?** Re-run the ATS verification prompt in file 5 with the exact JD. It's almost always a keyword or formatting issue, not a you-issue.

**Feeling overwhelmed?** Just do file 1 + file 5 today. One solid resume beats a half-finished "perfect" system.
