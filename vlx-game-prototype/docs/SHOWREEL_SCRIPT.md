## 录制规格

- **总时长**: 60 秒 (精确到帧)
- **分辨率**: 4K (3840x2160)
- **帧率**: 60fps
- **配乐**: 电子/合成器波 (Synthwave) → 高潮转 Orchestral Hit
- **音效设计**: 每个 Demo 切换配合 Whoosh + Sub-bass drop

## 字幕设计规范

- **位置**: 画面底部 1/3 处，安全区域内

## 录制技术要点

1. **Demo 1**: 需要录制屏幕 + 摄像头画中画（显示玩家表情）
2. **Demo 2**: 使用真实手机拍摄，展示"现实被 AR 叠加"的效果
3. **Demo 3**: 录制屏幕 + 手部特写（展示打字输入）
4. **转场**: 每个 Demo 切换使用"画面撕裂"或"像素化"转场
5. **色彩**: Demo 1 冷色调(蓝/青)，Demo 2 暖色调(金/紫)，Demo 3 对比强烈
