# dsh-tool-apistalk

API drift detection - schema monitoring, breaking change detection, migration impact analysis

## Tools

- schema_diff_detect
- breaking_change_analysis
- migration_impact_map
- compatibility_score
- api_deprecation_alert
- version_upgrade_advisor
- client_compatibility_check
- api_changelog_gen

## Install

```bash
npm install
npm run build
```
