# dsh-tool-regulator

Cross-Border Regulatory Compliance Radar - Policy change detection, compliance gap analysis, sanctions screening, tariff impact calculation, license requirement checking, deadline tracking, cross-border risk scoring, and regulation summarization

## Tools

- policy_change_detector
- compliance_gap_analyzer
- sanctions_screening
- tariff_impact_calculator
- license_requirement_checker
- regulatory_deadline_tracker
- cross_border_risk_scorer
- regulation_summarizer

## Install

```bash
npm install
npm run build
```
