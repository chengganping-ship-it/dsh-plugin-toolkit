# dsh-tool-fintech

Financial Risk & Fraud Detection Toolkit - Transaction monitoring, credit scoring, anti-money laundering detection, merchant risk assessment, identity verification, payment fraud detection, KYC compliance checking, and behavior biometrics analysis

## Tools

- transaction_monitor
- credit_scorer
- aml_detector
- merchant_risk_scorer
- identity_verification_scorer
- payment_fraud_detector
- kyc_compliance_checker
- behavior_biometrics_analyzer

## Install

```bash
npm install
npm run build
```
