# dsh-tool-legalmind

Legal Document Intelligence - Contract clause extraction, obligation tracking, legal risk scoring, NDA analysis, employment contract review, SLA evaluation, lease analysis, merger clause detection

## Tools

- contract_clause_extractor
- obligation_tracker
- legal_risk_scorer
- nda_analyzer
- employment_contract_reviewer
- sla_evaluator
- lease_agreement_analyzer
- merger_clause_detector

## Install

```bash
npm install
npm run build
```
