# dsh-tool-realestate

Real Estate Investment Analyzer - Property valuation, rental yield calculation, market timing, flip analysis, portfolio optimization, mortgage analysis, location scoring, and tax benefit calculation

## Tools

- property_valuator
- rental_yield_calculator
- market_timing_analyzer
- flip_analyzer
- portfolio_optimizer
- mortgage_analyzer
- location_scorer
- tax_benefit_calculator

## Install

```bash
npm install
npm run build
```
