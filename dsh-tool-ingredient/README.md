# dsh-tool-ingredient

Ingredient Compliance Scanner - Regulatory compliance checking, allergen scanning, banned substance detection, nutrition analysis, cosmetic safety scoring, label compliance auditing, and alternative ingredient finding

## Tools

- ingredient_parser
- regulatory_compliance_checker
- allergen_scanner
- banned_substance_detector
- nutrition_analyzer
- cosmetic_safety_scorer
- label_compliance_audit
- alternative_ingredient_finder

## Install

```bash
npm install
npm run build
```
