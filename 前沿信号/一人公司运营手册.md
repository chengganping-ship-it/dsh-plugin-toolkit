### 1. 内容生产（代替内容团队）

**每日日报/周报：**
```

1. 覆盖大模型、AI应用、AI基础设施三大方向
2. 每条新闻附来源链接和一句话点评
3. 末尾加"本周洞察"板块，给出2-3个投资/创业建议
4. 语气：专业但不晦涩，面向投资人和创业者
5. 篇幅：10条新闻+3条洞察，3000字左右
```

**公众号/知乎文章：**
```
帮我写一篇文章，标题："我从0到1搭建AI情報帝国的30天"
- 公众号风格，口语化，有故事性

**营销邮件：```
帮我写一封营销邮件，推广"前沿信号"Pro订阅：
- 目标：已有50个免费订阅者转化为付费
- 主题紧迫感强（限时优惠）
- 突出"每天3分钟节省2小时"的核心卖点

## 规避的最大坑

**坑1：追求完美产品**
→ 最小可用产品 = 一个PDF报告，邮件发送

**坑2：单个收入来源**
→ 产品+服务+内容+投资，4条腿

**坑3：只会动手不动脑**
→ 每周留半天只思考不执行

**坑4：忽视复利**
→ 今天的内容是明天的引流是后天的付费用户

**坑5：免费给别人干活**
→ 第一个客户就要收钱，不收钱=没价值
