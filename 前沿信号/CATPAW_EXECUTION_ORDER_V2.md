# Catpaw 指令 v2.0｜1万预算·苏州全职·跨境合规尖刀

> **收敛结论**: All-in A（跨境合规自动化），服务换现金 → 数据沉淀 → 产品化
> **执行窗口**: 2025-08-08 起 90 天
> **决策依据**: 资金≤1万排除B/C收购，苏州地理位置利好出口服务，AI+公开规则=唯一可行模式

---

# 操作者约束（铁律，所有任务不得突破）

- 总现金预算上限：人民币 10,000（含API、域名、工具订阅、交通）
- 人力：仅操作者1人全职 + AI辅助
- 驻地：中国苏州，可线上触达海外；必要时当天可往返上海/昆山/太仓
- 不做：收购、重资产、电力并网、需要牌照才能签字的最终法律责任承接
- 模式：先服务收费 → 再沉淀数据与工作流 → 再产品化
- 主赛道：跨境合规（HS归类 + 出口管制初筛），切口=跨境电商小包/出口拼货的「正式报关归类」

## Phase 0｜Day 1–7：验证（预算上限 ¥500）

### 任务0.1 规则与数据最小库（Day 1–2）

- 建立本地知识库目录 `/data/compliance/`：
  - HS：中国海关HS编码目录（公开）、美国HTS（USITC公开）、EU TARIC公开入口说明
  - 中国：两用物项/出口管制相关公开清单与公告索引（只存链接+摘要+生效日）
  - 美国：BIS Entity List / Denied Persons 的公开查询入口与更新记录方式
  - De minimis 终止后的正式报关要点（CBP公开材料摘要）
- 用脚本或结构化表格（CSV/SQLite）存储，字段至少含：
  code, description_cn, description_en, section_notes_link, update_date, risk_tags
- 禁止一上来做大而全爬虫；先手建 ≥200 条「电商高频品类」映射（3C配件、纺织、小家电、箱包、玩具、塑料件）。

### 任务0.2 访谈 15 人（Day 1–7，与0.1并行）

筛选：报关行经理/贸易合规/货代操作/跨境电商物控，≥3年经验。

渠道：
  - 苏州/昆山/上海出口企业、报关行（本地微信群、猎聘/脉脉关键词、展会名录）
  - 深圳跨境电商卖家/货代（线上）
  - 海外：Facebook/LinkedIn 上东南亚、北美小B货代（英语）

脚本：严格使用已校准的15题，额外必记3个数字：
  月票量、去年归类相关损失金额、愿付¥/票上限

输出：`/output/P0_interviews.md`
  - 每条访谈：痛点原话、可付费意愿、当前工具、是否愿试点
  - 汇总：Top3 可货币化场景、愿付费客户名单（≥3个意向）

### 任务0.3 手搓真单 20 票（Day 3–7）

- 从意向客户或公开商品标题中取 20 个真实品名，跑完全流程：
  输入品名/材质/用途 → HS初判（中美至少一侧）→ 置信度 → 法规依据 → 风险标记 → 人工复核结论
- 记录单票耗时、API成本、错误点
- 输出：`/output/P0_20cases.md` + 原始样例表

### Phase 0 通过门

- ≥2 家明确说「可以先试付费」
- 20 票里人工复核后可用率 ≥85%
- 单票可变成本（API）< ¥1

不通过 → 执行止损：收窄为「只接单一品类（如只做3C配件）」或转备胎代工，不进入Phase1产品化。

## Phase 1｜Day 8–30：服务现金流（预算上限 ¥2,000）

### 任务1.1 最小接单机器

- 渠道不建APP：企业微信/微信 + 飞书/表单 + 表格后台即可
- 报价单页（中英）：
  - 服务：出口HS初判+依据；可选出口管制关键词初筛
  - 价格：电商小包 ¥12–25/票（批量≥100票走¥8–12）；海外 $1.5–3/票
  - 交付：表格回传 + 争议项人工说明
  - 免责：最终申报责任在持证报关主体；本服务为辅助与初筛
- 接单目标：Day30 累计付费 ≥100 票，或 MRR 等价 ≥¥3,000

### 任务1.2 人机工作流（必须可复盘）

流水线固定为5步，禁止自由发挥：

1) 解析客户输入（品名/材质/图片OCR可选）
2) RAG检索本地HS与注释
3) LLM给出候选码（≤3个）+ 置信度 + 依据
4) 规则引擎打风险标签（管制词、敏感材料、认证提示）
5) 人工复核框（你自己）→ 导出

- 技术栈限廉价：DeepSeek/国产API优先（控成本），关键终判可对比一次高端模型；向量库用开源本地方案；总API预算本阶段 ≤¥800
- 每票记录成本、耗时、是否返工

### 任务1.3 获客（零广告或≤¥300测试）

优先级：
1. 访谈里愿付费的人 → 48h内给免费5票 → 转付费
2. 苏州/昆山外贸公司、货代：提供「De minimis后小包转正式报关」一页纸对照清单（内容获客）
3. 深圳电商卖家群：按「批量价」吃溢出单
4. 海外网络：用英语接「HS code assist for Amazon/Shopify exporters」只做辅助级

- 禁止烧钱投流

### 任务1.4 输出

`/output/P1_ops.md`：
  - 客户数、票数、收入、单票成本、复核时间、返工率
  - 客户原话（好评/差评）
  - 决定：是否达到进入Phase2的门闩

### Phase 1 通过门

- 付费客户 ≥2 且累计付费票 ≥100，或现金收入 ≥¥3,000
- 返工率 <15%
- 你的单票全耗时 <8 分钟（含复核）

不通过 → 停「产品梦」，只保留代工盈利模式，或执行止损清单转备胎。

## Phase 2｜Day 31–60：半自动 & 单位经济（预算上限 ¥3,000）

### 任务2.1 高频品类模板化

- 从真实订单中统计Top20品类，每类固化：
  特征问题清单（材质/功率/用途/是否带电等）→ 映射规则 → 常见误判
- 目标：Top20品类自动初判可用率 ≥90%，你只处理长尾

### 任务2.2 成本与定价纠偏

- 单票全成本压到收费价的 30% 以内
- 推出二档：
  - 仅HS初判（低价）
  - HS+管制初筛+底稿（高价）
- 不做罚款对赌

### 任务2.3 合规底稿能力（护城河雏形）

- 每票自动生成「审计底稿」：输入摘要、候选码、采用码、依据链接、模型版本、时间戳
- 这是未来不被纯ChatGPT替代的关键：可追溯，不是聊天

### 任务2.4 输出

`/output/P2_unit_economics.md`
  - 单票成本拆解、毛利、人效（票/小时）
  - MRR/累计收入
  - 是否出现「客户要API/批量接口」的信号

### Phase 2 通过门

- 人效 ≥10 票/小时（含复核）或 月收入 ≥¥8,000
- 单票成本 ≤ 收费的 30%
- 至少1家客户要求稳定复购或接口化

不通过 → 维持人工服务，不投入Phase3开发。

## Phase 3｜Day 61–90：尖刀产品化（预算上限 ¥4,000）

### 任务3.1 只做一把尖刀（禁止铺功能）

产品形态三选一（按Phase2信号决，默认a）：

a) 批量CSV：上传品名表 → 回传归类表+底稿（最适电商/货代）
b) 浏览器插件：在Amazon/Shopify/1688页面侧栏出HS建议
c) 极简API：1个endpoint，key计费

- 范围锁死：HS初判 + 置信度 + 依据 + 管制关键词初筛 + 底稿
- 不做：报关单全自动提交、关税支付、FTA原产地深度引擎

### 任务3.2 计费

- 订阅 + 按票：例如 ¥499/月含300票，超出¥1/票
- 或纯按票预充值
- 继续保留人工代办高价档（现金流压舱石）

### 任务3.3 护城河动作（每天1小时）

- 只做一件事：把真实误判与海关反馈回灌规则库
- 维护「裁定/公告」变更周记（手动即可）
- 输出周报：`/output/changelog_week_N.md`

### 任务3.4 90天里程碑（硬指标）

- 现金收入累计 ≥¥15,000 或 MRR ≥¥8,000
- 付费客户 ≥5
- 可复现底稿的批量交付链路稳定跑通
- 单票变动成本 ≤¥0.5（API+基础设施）

未达标：停止扩功能，回到服务模式活体现金流，重新评估赛道。

## 止损与备胎（写入日常检查）

每日/每周自检：

1. 现金余额是否仍覆盖 60 天 API+生活缓冲（生活费不从1万业务预算出则另计）
2. 若 OpenAI/国产品牌原生HS准确率在你的真集上 ≥90% 且稳定 → 立刻放弃「通用归类」宣传，改卖「底稿+管制初筛+人工复核工作流」
3. 若官方单一窗口/海关免费AI接口上线可用 → 转「管制筛查+企业台账+培训」或备胎
4. 备胎启动条件：Phase1门闩失败

备胎执行：
   - 定位「货代/报关行的隐形AI代工」
   - 按票报价低于市价20–30%
   - 不谈股权、不收购、不做品牌曝光
   - 目标：先连续30天日均利润 ≥¥200，再谈是否回主线

## 明确不做清单（防止飘）

- 不做电力并网/变压器/数据中心队列（预算与人脉不够）
- 不做报关行收购与注资换股
- 不做通用Agent平台、不做大而全合规ERP

- 不把预算砸进广告与办公门面
- 不在未验证前雇用全职人手
