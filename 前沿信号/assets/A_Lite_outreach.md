## 七、合规回访问题清单 (15题访谈脚本)

> **重要**:
> - 本脚本仅用于市场研究, 不涉及任何HS编码输出
> - 所有回答将脱敏后用于"概念验证", 不会透露被访者身份
> - 访谈不对任何实际商品提供归类/税率/申报建议
> - 访谈过程不录音（除非被访者明确同意）

### Part 1: 基本信息 (3题, 2分钟)

**Q1**: 您在做哪个品类/行业的出口或货代业务? 目的地是哪些国家?
> 记录: 品类 + 目的国 + 是否包含美国/欧盟

**Q2**: 您的团队每月大约处理多少票报关单/资料准备案例?
> 记录: 数量级 + 淡旺季波动

**Q3**: 在这个流程中, 您的角色是? 直接负责归类决策, 还是资料准备与协调?
> 记录: 角色定位 + 是否有持证经纪人签字确认环节

### Part 2: 流程痛点 (6题, 8分钟)

**Q4**: 从一个商品"客户提交资料"到"报关行准备完成", 平均耗时多长？
> 记录: 平均耗时 + 最快/最慢极端

**Q5**: 您经历的"返工"中, 最常见的原因是什么?(可多选)
- [ ] 商品描述不全/不准确
- [ ] 材质/成分信息缺失
- [ ] 功能/用途描述不清晰
- [ ] 翻译成目的语后歧义
- [ ] 目的国规则查询困难
- [ ] 现有工具/模板不匹配
- [ ] 客户未及时补充
- [ ] 其他: __________
> 记录: Top 3

**Q6**: 您的团队现在用什么工具辅助这些工作?
> 记录: 工具名称 + 满意度(1-5分) + 缺口

**Q7**: 在准备商品资料时, "目的国规则查询"这一环节, 您的团队平均要花多少时间?
> 记录: 分钟/小时数 + 主要查询哪里(官网/第三方/报关行咨询)

**Q8**: 如果用"6位HS候选编码 + 判定理由 + 官方条文引用 + 风险提示"这种形式交付, 对您的团队是否有帮助?
> 记录: 是否有帮助 + 需要什么附加条件 + 不需要/不需要的原因

**Q9**: 在您的合规流程中, 什么环节最容易导致延误或罚款?
> 记录: 具体环节 + 频率 + 严重程度

### Part 3: 需求测算 (4题, 5分钟)

**Q10**: 如果有一种服务, 帮您的团队把商品资料翻译成目的语 + 整理成标准化格式 + 提供规则查询路径（但不提供最终编码建议、不申报、不签字）, 您会花多少钱一个月购买?
> 记录: 价格点 + 决策条件

**Q11**: 您更倾向哪种交付形式?
- [ ] Excel/CSV 标准化表格
- [ ] 飞书/文档在线编辑
- [ ] API/系统对接
- [ ] 微信/邮件直传
- [ ] 都可以, 看质量
> 记录: 首选形式 + 原因

**Q12**: 什么样的情况下, 您不会购买这类服务？（冷静期后提问）
> 记录: 决策障碍 + 信任门槛

**Q13**: 您现在知道的或尝试过有哪些类服务?
> 记录: 竞品/替代品认知

### Part 4: 经纪人合作 (仅针对美国持牌经纪人, 3题, 5分钟)

**Q14**: 您目前在处理中国出口商的资料时, 最常见的资料问题是什么?
> 记录: 资料类型 + 频率 + 对审核效率的影响

**Q15**: 如果有第三方帮您在资料进入您审核前做标准化翻译和初步整理, 您会需要他们满足什么条件才愿意合作?
> 记录: 资质要求 + 责任边界 + 审核流程 + 费用模型

## 八、A-Lite 执行禁令清单

**执行此包时必须遵守的禁止项:**

| # | 禁止行为 | 原因 |
|---|---------|------|

| 7 | 签署或代理任何报关单据 | 违法 |
| 8 | 在消息中提到"归类""编码建议""税率建议" | 改变服务性质 |
| 9 | 未经同意录音/录屏 | 隐私/证据问题 |
