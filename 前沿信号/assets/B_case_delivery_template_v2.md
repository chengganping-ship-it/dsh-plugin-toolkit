### 4. 判定理由

```
品目归类依据:

  - 归类总规则: 规则三(二) - 基本特征判定为电气按摩功能

归类推理:
  1. 商品主要功能是通过低频脉冲缓解颈部肌肉疲劳，属于理疗/康复设备范畴
  2. 不属于药品、不属于化妆品、不是健身器材的专用部件
  3. 具备电气功能（脉冲+加热），但基本特征是"医疗/理疗设备"
  4. 排除备选1（8543.70）- 因为该品目为"本章未列名的电气设备"，而按摩设备在9018有专门列名
  5. 排除备选2（9506.91）- 因为健身器材不包括以理疗为主要目的的设备

结论: 首选候选编码为 9018.90, 因为9018的按摩设备品目条文直接包含按摩器具类商品，比未列名的电气品目更具体。
```

## 使用说明

### 这个模板怎么用

1. **复制一份空白模板**（本文件前半部分，不含演示案例）
2. **收到客户商品资料** → 填写商品资料摘要
3. **核验信息是否齐全** → 如果缺失, 列出追问项发给客户
4. **做HS候选判定** → 填入候选编码、判定理由
5. **检索官方依据** → 填入来源与检索日期，填写证据链状态
6. **填写风险提示** → 诚实地写"哪里不确定"
7. **发给客户前** → 确保免责声明在首尾可见
8. **客户回复确认** → 填入确认字段（含新增的4项）
9. **归档时** → 一份留在本地, 一份发给客户, 一份做脱敏后内部复盘素材

### 演示案例怎么用

这个案例存在的唯一目的是:
- **你自己练习时参考** — 看看一份完整交付长什么样
- **给信任的朋友预看** — 让他们理解你做什么、分析路径是什么、哪里是核验盲点
- **给自己做计时基准** — 看看跑一份完整交付要多久
- **展示如何使用"候选"而非"确定"表述** — 模板的核心约束
