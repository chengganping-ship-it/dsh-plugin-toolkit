## 🚀 快速启动

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 测试采集
```bash
python scripts/collector.py
```

### 3. 部署落地页
- 将 `web/index.html` 托管到：
  - GitHub Pages（免费）
  - Netlify（免费）
  - 你的服务器（推荐，完全自主）

### 4. 启动定时任务
```bash
python scripts/scheduler.py
```
