---

## P1 目标 (一句话)

> **证明"一封英文询盘邮件进, 一页结构化草稿出"可以在 10 分钟内完成, 且全程无自动外发。**

---

## P1 做什么 (In Scope)

| 项 | 说明 |
|----|------|
| 入口 | 唯一: 邮件转发到指定测试邮箱 |
| 解析 | PDF 文本/OCR + Excel 结构提取 + 图片 OCR |
| 抽取 | LLM 输出结构化 JSON (按 RFQ_intake_schema.md 精简版) |
| 校验 | 4 类客观冲突检测 (数量/公差/材质-表面处理/交期物理不可能) |
| 输出 | 飞书多维表格一行 + 飞书通知 + 回复草稿文档 |
| 审批 | 人工在飞书复核, 人工决定是否复制/修改/发送 |
| 安全 | 开工闸门清单 (internal/RFQ_data_safety_checklist.md § 一) |

---

## P1 不做什么 (Out of Scope)

| 项 | 原因 |
|----|------|
| 自动发送邮件/消息 | 风险红线, P3 前禁碰 |
| 自动报价/报交期/承诺认证 | 商业/法律责任 |
| 多入口渠道 (微信/WhatsApp/Shopify) | P1 只接邮件 |
| CRM/ERP 接口 | P1 只写飞书 |
| 历史邮件批量抓取 | 只用客户专门转发的测试邮件 |
| 多行业通用模板 | 优先机械零部件行业 |
| 复杂工作流编排 | 6 步最小闭环 |

## P1 完成标准 (Go/No-Go)

| 标准 | 指标 |
|------|------|
| 访谈验证 | ≥ 5 家苏州工厂, ≥ 3 家确认"整理 RFQ 是明确痛点" |

| 关键字段准确率 | 数量/材料/尺寸 ≥ 95% |
| 数字准确率 | ≥ 98% |
| 审批闸门 | 价格/交期/认证字段 100% 标记 HUMAN_APPROVAL_REQUIRED |

| 单次处理耗时 | ≤ 10 分钟 (从邮件到飞书写入, 不含人工复核) |
| 真实试点意向 | ≥ 1 家真人说"愿意拿真实历史邮件做脱敏测试" |
