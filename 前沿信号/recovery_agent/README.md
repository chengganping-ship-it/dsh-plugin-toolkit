# Recovery Agent / 现金流找回机器人

> 不是预测价格，而是找回企业已经丢掉的每一分钱

## 适用异常类型（首批5类）

1. 物流丢件未赔付：丢件但没申请物流赔偿
2. 延误赔偿未申请：超时但没申请延误赔偿
3. 平台退款漏记：已退款但卖家账户未到账
4. 重复扣费：同一笔费用被多次收取
5. 订单与结算不一致：实收≠应收

## 收费模型

免费审计 → 发现异常 → 客户确认 → 协助追回 → 按实际到账收15-25%

## 硬门槛

- 预估可追回金额 / 变量成本 > 5
- 单客户首次价值验证 < 7天
- 人工复核时间 < 2小时/客户
- 误报率 < 15%
