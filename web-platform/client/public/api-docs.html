API Documentation

Complete reference for the Funding Mirror REST API and WebSocket streams. 185+ endpoints delivering real-time crypto arbitrage intelligence.

Overview

Base URL
https://api.fundingmirror.io
WebSocket URL
wss://api.fundingmirror.io/ws
Authentication
Bearer Token
Response Format
JSON
All API requests must be made over HTTPS. HTTP requests are rejected. Timestamps are returned in ISO 8601 format (UTC).

Rate Limits

Tier Requests/Minute WebSocket Concurrent Streams

Authentication

API Key

All API requests require authentication via a Bearer token in the authorization header. You can generate an API key from your Dashboard → Settings → API Keys.

Header Format

HTTP Header
Authorization: Bearer fm_live_xxxxxxxxxxxxxxxxxxxxxxxx

Example Request

cURL
# Fetch funding rate data curl -X GET "https://api.fundingmirror.io/v6/funding-rates" \ -H "Authorization: Bearer fm_live_xxxxxxxxxxxxxxxxxxxxxxxx" \ -H "Content-Type: application/json"
Keep your API keys secure. Never expose them in client-side code or public repositories. Use environment variables or a secrets manager.

WebSocket API

The WebSocket API provides real-time streaming data for funding rates, arbitrage signals, and market events. Connection is available on Pro and Enterprise plans.

Connection URL

WebSocket
wss://api.fundingmirror.io/ws?token=fm_live_xxxxxxxxxxxxxxxxxxxxxxxx

Subscribe Message

JSON
{ "action": "subscribe", "channels": [ "funding_rates", "arbitrage_signals", "mev_alerts", "yield_updates" ], "symbols": ["BTC", "ETH", "SOL"] }

Event Types

Event Description Frequency
funding_rate_update New funding rate data available Every 8 hours
arbitrage_signal Profitable arbitrage opportunity detected Real-time
mev_alert MEV activity detected Real-time
yield_shift Significant yield rate change Every 5 min
liquidation_event Large liquidation detected Real-time

SDK Examples

Python

Python
import requests API_KEY = "fm_live_xxxxxxxxxxxxxxxxxxxxxxxx" BASE_URL = "https://api.fundingmirror.io" headers = { "Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json", } # Fetch funding rate heatmap response = requests.get( f"{BASE_URL}/v12/funding-heatmap", headers=headers, params={"symbol": "BTC", "timeframe": "8h"} ) data = response.json() print(data)

JavaScript

JavaScript
const API_KEY = 'fm_live_xxxxxxxxxxxxxxxxxxxxxxxx'; const BASE_URL = 'https://api.fundingmirror.io'; // Fetch arbitrage signals async function getArbitrageSignals() { const res = await fetch(`${BASE_URL}/v9/spreads?min_profit=0.5`, { headers: { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json', }, }); const data = await res.json(); console.log(data); } getArbitrageSignals();

Go

Go
package main import ( "encoding/json" "fmt" "io/ioutil" "net/http" ) func main() { apiKey := "fm_live_xxxxxxxxxxxxxxxxxxxxxxxx" url := "https://api.fundingmirror.io/v13/sentiment?market=BTC" req, _ := http.NewRequest("GET", url, nil) req.Header.Set("Authorization", "Bearer "+apiKey) req.Header.Set("Content-Type", "application/json") client := &http.Client{} resp, _ := client.Do(req) defer resp.Body.Close() body, _ := ioutil.ReadAll(resp.Body) var data map[string]interface{} json.Unmarshal(body, &data) fmt.Println(data) }
