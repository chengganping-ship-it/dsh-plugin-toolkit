## 使用指南

### Midjourney 推荐参数

| 场景 | Aspect Ratio | Stylize | Version |
|------|-------------|---------|---------|
| Hero Banner | `--ar 16:9` | `--s 250` | `--v 6.1` |
| Feature Cards | `--ar 4:3` | `--s 150` | `--v 6.1` |
| Icons/Social Proof | `--ar 1:1` | `--s 100` | `--v 6.1` |

### Stable Diffusion 推荐参数

| 参数 | 推荐值 |
|------|-------|
| Sampler | DPM++ 2M Karras |
| Steps | 30-40 |
| CFG Scale | 7-8 |
| Resolution | 1024x768 / 1344x768 / 768x1344 |
| Model建议 | SDXL Base + Refiner / DreamShaper XL / Juggernaut XL |
