# Kimodo Product - GTM (Go-To-Market) 商业策略

## 1. 产品定位

**一句话定位**：世界上第一个本地运行的文本→3D动作生成引擎，让独立创作者用自然语言创造专业级动画

**核心价值主张**：
- 🔒 **隐私优先**：所有推理本地完成，无需上传数据到云端
- 💰 **零 API 费用**：一次购买/订阅，无限生成
- ⚡ **实时生成**：2-5秒内产出3D动作
- 🎮 **多格式输出**：FBX/BVH/AMASS，直接导入 Unity/Unreal/Blender

## 4. B端销售话术与痛点打击

### 4.1 游戏/动画工作室

**核心痛点**：
- 传统动捕棚租金：$500-2000/小时
- 外包动画师：$50-150/秒
- 从 text concept 到可用动画：2-5天周期

**Kimodo 价值**：
> "在传统流程中，你的美术需要 2 天才能把设计文档变成可用的动画文件。使用 Kimodo，2 秒预览，2 分钟导出最终资产。不止快——你的美术可以无限次迭代，零额外成本。"

**客单价路径**：
- 小工作室：Pro 版 $29/月 × 5人 = $14/月 (决策人: 技术总监)
- 中型工作室：Studio $99/月 × 20席位 = $1,980/月 (决策人: CTO/制作总监)
- 大型工作室：Enterprise 私有化 $5-20万 (决策人: VP + IT + 采购)

### 4.2 数字人/直播公司

**核心痛点**：
- 面捕方案：延迟高、表情有限、需要专业设备
- 云端 API：持续成本、断网风险、数据隐私
- 动作库购买：$500-2000/套，样式有限

**Kimodo 价值**：
> "你的数字人需要丰富的肢体语言来活跃气氛。Kimodo 让运营团队用自然语言实时生成动作——'比个心'、'跳一段舞'、'向观众鞠躬'——无需动捕设备，无需等待外包。"

**杀手功能**： WebSocket 实时流 → 数字人控制器 → 直播软件 OBS 字幕触发联动

### 4.3 机器人训练/仿真

**核心痛点**：
- 真实数据采集：昂贵、危险、难以覆盖边缘场景
- 仿真环境动作：手工编写耗时、不自然

**Kimodo 值**：
> "用自然语言描述机器人需要执行的动作，自动生成物理合规的运动轨迹。输入'pick up a fragile cup carefully'，输出考虑重力、关节限位的平滑轨迹。"
