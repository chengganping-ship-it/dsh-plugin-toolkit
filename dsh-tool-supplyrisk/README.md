# dsh-tool-supplyrisk

Supply Chain Risk Early Warning System - Supplier health scoring, geopolitical risk mapping, disruption early warning, alternative supplier finding, logistics bottleneck detection, cost volatility tracking, single-source detection, and resilience scoring

## Tools

- supplier_health_scorer
- geopolitical_risk_mapper
- disruption_early_warning
- alternative_supplier_finder
- logistics_bottleneck_detector
- cost_volatility_tracker
- single_source_detector
- supply_chain_resilience_scorer

## Install

```bash
npm install
npm run build
```
