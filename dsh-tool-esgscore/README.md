# dsh-tool-esgscore

ESG Supply Chain Scorer - Carbon footprint calculator, labor practice scorer, governance compliance checker, supply chain transparency index, ESG risk heatmap, sustainability report generator, stakeholder impact assessor, ESG benchmarking

## Tools

- carbon_footprint_calculator
- labor_practice_scorer
- governance_compliance_checker
- supply_chain_transparency_index
- esg_risk_heatmap
- sustainability_report_generator
- stakeholder_impact_assessment
- esg_benchmarking

## Install

```bash
npm install
npm run build
```
