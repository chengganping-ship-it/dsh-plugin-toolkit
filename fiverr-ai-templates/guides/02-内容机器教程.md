# 📝 AI 内容机器 - 详细教程

> 工作流文件：`1-ai-content-machine.json`
> 功能：自动监控 RSS 源 → GPT 生成摘要和社媒草稿 → 保存到 Google Sheets + Telegram 通知

---

## 工作流架构图

```
[RSS Feed Trigger] → [Filter Last 24h] → [GPT-4o Content Generator] → [Save to Google Sheets]
                                                              ↘
                                                        [Telegram Notification]
```

---

## 适用场景

- **内容营销团队**：自动追踪行业新闻，快速生成社媒内容
- **独立创作者**：将外文资讯自动翻译+摘要，发布到中文平台
- **跨境电商**：监控竞品/行业动态，自动生成产品描述灵感
- **自媒体运营**：每日自动聚合热点，减少信息搜集时间

## 详细配置步骤

### 1. 配置 RSS 源

默认源是 VentureBeat（科技新闻）。你可以替换为任何 RSS 源：

**热门 RSS 源推荐**：
| 领域 | RSS URL |
|------|---------|
| 科技 | `https://feeds.feedburner.com/venturebeat/SZYF` |
| AI 动态 | `https://blog.google/technology/ai/rss/` |
| 营销 | `https://contentmarketinginstitute.com/feed/` |
| 电商 | `https://www.practicalecom.com/feed/` |
| 中文科技 | `https://www.36kr.com/feed` |

**修改方法**：
1. 双击 **RSS Feed Trigger** 节点
2. 在 `URL` 字段粘贴你的 RSS 地址
3. 保存

### 2. 自定义 GPT Prompt

默认 Prompt 生成中文摘要 + Twitter + LinkedIn 草稿。你可以修改为：

**示例：电商产品灵感版**
```
你是一个跨境电商内容专家。请根据以下文章生成：
1. 3 个潜在产品机会（每个 50 字）
2. 每个产品的目标市场和竞争分析
3. 一个亚马逊产品标题 + 5 个 bullet point（英文）
4. 一个 Facebook 广告文案草稿（英文，100 字）
```

**修改方法**：
1. 双击 **GPT-4o Content Generator** 节点
2. 找到 `messages` → `System` content
3. 替换为你自己的 Prompt
4. 保存

### 3. 配置 Google Sheets

**创建表格**：
1. 打开 [Google Sheets](https://sheets.google.com) → 新建空白表格
2. 重命名为 "AI Content Machine"
3. 在第一行创建列标题：`Date | Source | Summary | Link`
4. 从 URL 复制 Spreadsheet ID
5. 粘贴到 n8n 节点的 `Document ID` 字段

### 4. 配置 Telegram 通知

1. 在 Telegram 找 **@BotFather**
2. 发送 `/newbot` → 按提示命名 → 获得 Token
3. 创建一个频道/群组，把 Bot 加进去
4. 给 Bot 发一条消息（如 "hello"）
5. 浏览器访问：`https://api.telegram.org/bot<你的TOKEN>/getUpdates`
6. 在返回的 JSON 中找到 `chat.id`（一串数字）
7. 粘贴到 n8n Telegram 节点的 `Chat ID` 字段

## 高级玩法

### 添加更多输出平台

在 GPT 节点后添加：
- **Twitter 节点**：自动发布到 X/Twitter
- **WordPress 节点**：自动发布为博客文章
- **Notion 节点**：保存到 Notion 数据库
- **Slack 节点**：推送到团队 Slack 频道

### 修改发布频率

双击 **RSS Feed Trigger** → 修改 `Run Every` 字段：
- 每小时检查一次：`Hours` = 1
- 每 6 小时：`Hours` = 6
- 每天一次：`Days` = 1

### 添加更多 RSS 源

复制 RSS 节点 → 修改 URL → 连接到同一个 Filter 节点。多个源的内容会汇聚到同一个工作流处理。

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| RSS 节点报错 "Invalid XML" | 检查 RSS URL 是否有效（浏览器打开验证） |
| GPT 输出为空 | 检查 OpenAI API Key 和余额 |
| Google Sheets 写入失败 | 确认 Sheet 名称与节点配置一致 |
| Telegram 没收到通知 | 检查 Chat ID 和 Bot Token，确认 Bot 在群组中 |
