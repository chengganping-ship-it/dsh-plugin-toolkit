# 🚀 n8n AI 自动化模板包 - 快速入门指南

> 欢迎！本指南将帮助你在 **10 分钟内** 运行第一个 AI 自动化工作流。

---

## 前置条件

在开始之前，请确保你拥有：

- [ ] 一个 **n8n** 账号（[cloud.n8n.io](https://cloud.n8n.io) 免费版即可，或本地部署）
- [ ] 一个 **OpenAI API** 密钥（[platform.openai.com](https://platform.openai.com) → API Keys）
- [ ] 一个 **Google 账号**（用于 Google Sheets 集成）
- [ ] 一个 **Telegram Bot Token**（可选，用于通知功能）

---

## 第一步：导入工作流

1. 登录 n8n 控制台
2. 点击左侧菜单 **Workflows** → 右上角 **Import from File**
3. 选择对应的 `.json` 文件（如 `1-ai-content-machine.json`）
4. 点击 **Import** — 工作流已加载到你的面板！

---

## 第二步：配置 API 密钥

每个工作流都需要连接你的 API 密钥。方法如下：

### OpenAI API
1. 在 n8n 中，点击任意 **OpenAI** 节点
2. 在右侧面板找到 **Credential** 下拉框 → 点击 **+ Create New**
3. 输入名称（如 "My OpenAI Key"）和你的 API Key
4. 点击 **Save** — 所有 OpenAI 节点将自动关联

### Google Sheets
1. 点击任意 **Google Sheets** 节点
2. 点击 **+ Create New** Credential
3. 系统会弹出 Google 授权页面 → 登录并授权
4. 授权完成后自动返回 n8n

### Telegram Bot（可选）
1. 在 Telegram 找 **@BotFather** → 发送 `/newbot` 创建机器人
2. 复制 Bot Token
3. 在 n8n 的 Telegram Credential 中粘贴 Token

---

## 第三步：自定义配置

每个工作流都有 **YOUR_*** 占位符需要替换：

| 占位符 | 说明 | 获取方式 |
|--------|------|---------|
| `YOUR_OPENAI_CREDENTIAL_ID` | OpenAI 凭证 ID | 第二步自动创建 |
| `YOUR_GOOGLE_DOC_ID` | Google 文档 ID | 从 URL 复制 |
| `YOUR_TELEGRAM_CHAT_ID` | Telegram 聊天 ID | 给 Bot 发消息后访问 `https://api.telegram.org/bot<TOKEN>/getUpdates` |
| `YOUR_APOLLO_API_KEY` | Apollo.io API Key | apollo.io 注册获取（免费额度） |

### 如何找到 Google Doc ID
打开你的 Google Sheet，URL 格式为：
`https://docs.google.com/spreadsheets/d/`**`THIS_IS_THE_ID`**`/edit`
复制 ID 粘贴到对应节点即可。

---

## 第四步：测试运行

1. 点击工作流画布右上角的 **Execute Workflow** 按钮
2. 观察每个节点的执行状态（绿色 = 成功，红色 = 失败）
3. 检查 Google Sheets 是否有新数据写入
4. 如果收到 Telegram 通知 → 🎉 恭喜，运行成功！

---

## 第五步：激活自动化

测试通过后：
1. 点击工作流画布左上角的 **Active** 开关（灰色 → 绿色）
2. 工作流将按照设定时间自动运行（如 RSS 每小时检查一次）
3. 你可以在 **Executions** 标签页查看历史执行记录

## 常见问题

**Q: 提示 "Credential not found"？**
A: 确保你在节点中选择了正确的 Credential。点击节点 → 右侧面板 → Credential 下拉框 → 选择你创建的密钥。

**Q: OpenAI 节点报错 "Insufficient Quota"？**
A: 你的 OpenAI 账号余额不足。前往 platform.openai.com 充值或检查 API Key 是否正确。

**Q: Google Sheets 没有数据？**
A: 检查 Sheet 名称是否与教程中一致（区分大小写），以及 Google 账号是否有编辑权限。

**Q: 可以修改 Prompt 吗？**
A: 当然可以！双击 OpenAI 节点 → 修改 System Prompt 或 User Prompt → 保存。这是模板的强大之处：完全可定制。
