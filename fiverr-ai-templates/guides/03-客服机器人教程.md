# 🤖 AI 客服机器人 - 详细教程

> 工作流文件：`2-ai-customer-support.json`
> 功能：接收客服表单 → GPT 意图分类+自动回复 → 简单问题自动处理，复杂问题升级人工

---

## 工作流架构图

```
[Webhook - New Ticket] → [GPT-4o Intent Classifier] → [Needs Human?]
                                                      ├─ No → [Send Auto Reply] → [Log Auto-Resolved]
                                                      └─ Yes → [Alert Human via Telegram] → [Log Escalated]
```

---

## 适用场景

- **电商店铺**：自动回复订单查询、退换货、物流追踪等高频问题
- **SaaS 产品**：处理常见技术问题（密码重置、功能使用等）
- **教育平台**：回答课程安排、作业提交、账号问题
- **本地服务**：预约咨询、价格询问、营业时间等

## 详细配置步骤

### 1. 配置 Webhook（接收客户消息）

Webhook 是一个 URL，你的网站/表单通过它向 n8n 发送客户消息。

**获取 Webhook URL**：
1. 双击 **Webhook - New Ticket** 节点
2. 复制 `Webhook URL`（如 `https://your-n8n.app/webhook/xxx/support-ticket`）
3. 在你的网站表单中，将此 URL 设为 POST 目标

**JSON 数据格式**：
你的表单需要发送以下 JSON：
```json
{
  "email": "customer@example.com",
  "message": "我的订单什么时候发货？",
  "order_id": "ORD-2026-001",
  "ticket_id": "TKT-001"
}
```

### 2. 自定义 GPT Prompt（意图分类逻辑）

默认分类：`billing / technical / shipping / general / urgent`

**示例：电商客服版**
```
你是电商客服分类器。请分析客户消息：

1. 意图分类（单选）：
   - order_status: 订单状态查询
   - shipping: 物流/配送问题
   - return_refund: 退货/退款
   - product_info: 产品咨询
   - complaint: 投诉/不满
   - other: 其他

2. 情感评分（1-10）

3. 自动回复草稿（中文，150-250 字，语气友好专业）

4. 是否需要人工（情感<3 或意图=complaint 时为 true）

JSON 输出格式：{"intent":"...", "sentiment":N, "reply_draft":"...", "needs_human":true/false}
```

### 3. 配置 SMTP（发送邮件回复）

**使用 Gmail**：
1. 开启 Gmail 两步验证
2. 生成 **App Password**（[Google Account](https://myaccount.google.com) → Security → App Passwords）
3. 在 n8n SMTP Credential 中：
   - Host: `smtp.gmail.com`
   - Port: `465`
   - User: 你的 Gmail 地址
   - Password: App Password（不是 Gmail 密码！）

**使用其他邮箱**：
- QQ 邮箱：`smtp.qq.com`, Port `465`
- Outlook: `smtp.office365.com`, Port `587` (STARTTLS)
- 企业邮箱：咨询你的 IT 部门获取 SMTP 信息

### 4. 接入现有客服系统

**WordPress Contact Form 7**：
1. 安装 CF7 插件
2. 创建表单，添加你的字段
3. 在表单设置中添加 "Additional Headers"：`Content-Type: application/json`
4. 使用 CF7 的 `wpcf7_before_send_mail` Hook，调用 Webhook URL

**Shopify**：
1. 使用 Shopify Flow 或第三方 app（如 Zapier/Make）
2. 当新客服工单创建时 → 触发 HTTP POST 到 n8n Webhook

**自定义网站**：
```javascript
// 前端表单提交示例
fetch('https://your-n8n.app/webhook/xxx/support-ticket', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: document.getElementById('email').value,
    message: document.getElementById('message').value,
    order_id: document.getElementById('order-id').value
  })
});
```

## 高级玩法

### 添加知识库（RAG）

在 GPT 节点前添加 **Vector Store** 节点：
1. 将 FAQ 文档添加到 Pinecone/Weaviate 向量数据库
2. 在 Prompt 中加入检索到的相关知识
3. 自动回复将基于你的产品文档生成

### 多语言支持

修改 Prompt 添加语言检测：
```
5. 检测消息语言：cn/en/jp/...
6. 自动回复使用相同语言
```

### 工作时间控制

添加 **IF 节点** 在工作时间外自动回复"稍后处理"：
```
在工作时间外（21:00-09:00）→ 发送"我们已收到消息，工作时间将优先处理"
```

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| Webhook 收不到消息 | 用 [webhook.site](https://webhook.site) 测试你的表单是否正确发送 JSON |
| 邮件进入垃圾箱 | 配置 SPF/DKIM 记录，或换用 SendGrid/Postmark 等专业邮件服务 |
| GPT 分类不准确 | 在 Prompt 中加入更多示例（few-shot learning） |
| JSON 解析失败 | 检查 GPT 输出是否严格符合 JSON 格式，必要时添加 Try-Catch 节点 |
