# dsh-tool-cryptosignal

Crypto Arbitrage Signal Engine - Funding rate arbitrage, cross-exchange spreads, whale tracking, liquidation heatmaps, volatility regime, basis spread, opportunity scoring

## Tools

- funding_rate_analyzer
- cross_exchange_spread
- whale_movement_tracker
- liquidation_heatmap
- volatility_regime
- basis_spread_monitor
- arbitrage_opportunity_scorer
- historical_funding_backtest

## Install

```bash
npm install
npm run build
```
