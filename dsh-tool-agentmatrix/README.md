# dsh-tool-agentmatrix

Multi-Agent Collaboration Matrix plugin for DeepSeek Harness (DSH).

Dynamic role assignment, task orchestration, capability matching, progress visualization.

## Tools

| Tool | Description |
|------|-------------|
| `agent_role_assign` | Dynamically assign agent roles by capabilities and workload |
| `task_orchestrate` | Decompose tasks into scheduled DAG with phases |
| `capability_match` | Match agents to task requirements with scoring |
| `collaboration_graph` | Analyze agent collaboration network and bottlenecks |
| `conflict_resolution` | Detect and resolve multi-agent conflicts |
| `workload_balance` | Balance workload across agents with transfer suggestions |
| `progress_dashboard` | Track project progress with per-agent rates and risks |
| `team_health_check` | Evaluate agent system health (latency, errors, uptime) |

## Install

```bash
npm install
npm run build
```
