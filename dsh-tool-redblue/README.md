# dsh-tool-redblue

Red-Blue Team Security Audit plugin for DeepSeek Harness (DSH).

Auto penetration testing, defense verification, compliance mapping, fix prioritization.

## Tools

| Tool | Description |
|------|-------------|
| `red_team_pentest` | Simulate OWASP Top 10 attacks on code/configs |
| `blue_team_defense` | Verify existing security controls effectiveness |
| `audit_compliance_map` | Map vulnerabilities to OWASP/CWE/NIST/ISO2701/SOC2/GDPR |
| `exploit_chain_analysis` | Analyze chained vulnerabilities forming exploit paths |
| `defense_gap_scan` | Identify missing security controls |
| `attack_surface_map` | Map application attack surface and heat zones |
| `fix_priority_matrix` | Prioritize fixes by CVSS, effort, and business impact |
| `threat_model_gen` | Generate STRIDE threat models |

## Install

```bash
npm install
npm run build
```
