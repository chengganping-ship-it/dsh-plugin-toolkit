# dsh-tool-governance

Agent Security Governance Plugin - Permission Auditing, Compliance Checking, Guardrail Design, Audit Trail Generation, Data Leak Detection, Tool Sandbox Scoring, Prompt Injection Detection, Governance Maturity Assessment

## Tools

- permission_auditor
- compliance_checker
- guardrail_designer
- audit_trail_generator
- data_leak_detector
- tool_sandbox_scorer
- prompt_injection_detector
- governance_maturity_assessor

## Install

```bash
npm install
npm run build
```
