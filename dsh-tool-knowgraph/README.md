# dsh-tool-knowgraph

Knowledge Graph Builder - Entity extraction, relationship mapping, graph analysis, knowledge triple generation, entity resolution, semantic search, graph visualization data, and graph centrality analysis

## Tools

- entity_extractor
- relationship_mapper
- graph_builder
- knowledge_triple_generator
- entity_resolver
- graph_analyzer
- semantic_search
- graph_visualization_data

## Install

```bash
npm install
npm run build
```
