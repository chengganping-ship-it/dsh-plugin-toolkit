# DSH Plugin: dsh-tool-travelplanner

**Intelligent Travel Planner** - Multi-source coordination, itinerary optimization, booking strategy, and carbon footprint calculation for DeepSeek Harness.

## Overview

`dsh-tool-travelplanner` is a comprehensive travel planning plugin for DSH (DeepSeek Harness) that coordinates multiple data sources - calendars, booking platforms, travel information services, and environmental data - to deliver intelligent travel planning. Inspired by Anthropic's research on cross-calendar multi-source coordination scenarios.

## Features

### 8 Tools

| # | Tool | Description |
|---|------|-------------|
| 1 | `itinerary_optimizer` | Route optimization with day-by-day scheduling, preference matching, and cost estimation |
| 2 | `budget_planner` | Comprehensive budget breakdown with savings strategies and per-person analysis |
| 3 | `booking_strategist` | Optimal booking timing, channel recommendations, and loyalty optimization |
| 4 | `calendar_coordinator` | Conflict detection across work/family calendars with resolution suggestions |
| 5 | `local_discovery` | Personalized recommendations for food, culture, hidden gems, and day trips |
| 6 | `contingency_planner` | Emergency contacts, scenario plans, insurance notes, and backup options |
| 7 | `travel_document_checker` | Visa/passport requirements, validity checks, and renewal recommendations |
| 8 | `carbon_footprint_calculator` | Emissions quantification with offset options and reduction tips |

## Installation

```bash

```

## Usage

Register the plugin with DSH and call tools via the agent:

```typescript
// Example: Optimize an itinerary
const result = await agent.call('itinerary_optimizer', {
  itinerary_input: JSON.stringify({
    destinations: [
      { name: 'Tokyo', country: 'Japan', duration_days: 4, priority: 'must_visit', best_season: ['spring', 'fall'], avg_daily_cost_usd: 150, travel_time_from_prev_hours: 0, category: 'city' },
      { name: 'Kyoto', country: 'Japan', duration_days: 3, priority: 'must_visit', best_season: ['spring', 'fall'], avg_daily_cost_usd: 120, travel_time_from_prev_hours: 2.5, category: 'cultural' },
    ],
    duration: 7,
    preferences: { pace: 'moderate', interests: ['food', 'culture', 'photography'], travel_style: 'comfort', avoid: [], must_include: ['temples'] },
    constraints: { max_budget_usd: 3000, fixed_dates: { start: '2025-04-01', end: '2025-04-07' }, max_travel_hours_per_day: 4, mobility_requirements: [] }
  })
})
```

## Tool Details

### itinerary_optimizer
- **Input**: destinations[], duration, preferences, constraints
- **Output**: Optimized route, day-by-day plan, cost estimates, warnings, tips
- **Algorithm**: Priority-weighted nearest-neighbor heuristic with pace adjustment

### budget_planner
- **Input**: travel_style, destinations[], duration, currency, travelers, include_flights
- **Output**: Category breakdown, savings strategies, per-person/per-day costs
- **Styles**: luxury, comfort, budget, backpacker

### booking_strategist
- **Input**: travel_dates, flexibility_days, loyalty_programs[], booking_targets[], trip_type, advance_notice_days
- **Output**: Per-target booking windows, channels, price trends, urgency levels

### calendar_coordinator
- **Input**: travel_dates, work_calendar[], family_calendar[], delegates[], importance_threshold
- **Output**: Conflicts, reschedulable/delegable items, prep checklist, auto-reply template

### local_discovery
- **Input**: destination, interests[], dietary_restrictions[], budget_level, travel_dates, group_size, mobility_needs[]
- **Output**: Recommendations, food spots, hidden gems, day trips, local tips, safety notes

### contingency_planner
- **Input**: trip_details, risk_factors[], traveler_profiles[], budget_contingency_percent
- **Output**: Emergency contacts, scenario plans, insurance notes, document checklist, communication plan

### travel_document_checker
- **Input**: nationality, destinations[], travel_dates, passport_expiry, existing_visas[], traveler_age, special_circumstances[]
- **Output**: Requirements per destination, passport status, action items, visa timeline

### carbon_footprint_calculator
- **Input**: transport_modes[], accommodation_type, nights, activities[], include_offset
- **Output**: CO2 breakdown, offset options, reduction tips, benchmarks

```
├── cordis.yml            # DSH plugin manifest
├── README.md             # This file
├── src/
│   └── index.ts          # Plugin source with 8 tools (~1400 lines)
└── lib/                  # Compiled output (generated by tsc)
```

## Technical Notes

- **Deterministic outputs**: Uses `seededRandom()` for reproducible recommendations
- **Type-safe**: Full TypeScript interfaces for all inputs/outputs
- **Markdown output**: All tools return formatted markdown with tables and emoji indicators
- **No external API calls**: All computation is self-contained for reliability
