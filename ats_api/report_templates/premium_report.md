## ATS Optimization Masterclass

### 1. Keyword Placement Hierarchy

ATS systems weight keywords differently based on position:

1. **Professional Summary** — Highest weight, place all Critical keywords here
2. **Job Title / Headline** — Include target role title verbatim
3. **Skills / Technical Skills Section** — Dense keyword placement, no penalty
4. **First Bullet of Each Role** — High visibility, place keywords early
5. **Remaining Bullets** — Natural integration of supporting keywords

### 2. ATS Formatting Rules

| Do | Don't |
|----|-------|
| Standard section headings (Experience, Skills, Education) | Creative headings |
| Simple bullet points | Tables, text boxes, columns |
| Standard fonts (Arial, Calibri, Garamond) | Icons, images, graphics |
| .docx or PDF (text-based) | JPEG/PNG resume scans |
| Spell out AND abbreviate acronyms | Use only abbreviations |
| Consistent date formats | Mixed date styles |

### 3. Keyword Density Guidelines

- **Critical keywords:** 3-5 mentions across resume
- **High keywords:** 2-3 mentions
- **Medium keywords:** 1-2 mentions
- **Total keyword density:** 3-5% of total resume text

### 4. Synonym Strategy

Some ATS systems use semantic matching. Cover your bases:

- **[keyword]** — Also consider: [variations/synonyms]
