# 轻量级有声书生成器

基于 edge-tts（微软免费语音合成）的有声书/播客生成工具。

## 特点

- **完全免费** — edge-tts 使用微软 Edge 在线语音服务，无需 API Key
- **零额外依赖** — 只需 Python 3.8+ 和 edge-tts
- **中文效果好** — 微软神经网络语音，自然流畅
- **支持 TXT/EPUB** — 自动识别章节，批量转换
- **章节合并** — 自动将每章合并为单个 MP3
- **断点续传** — 已生成的片段自动跳过

## 快速开始

### 基本用法

```bash
# 转换文本文件
python simple_audiobook.py 你的小说.txt

# 指定输出目录并合并章节
python simple_audiobook.py 你的小说.txt -o 输出目录 --merge

# 选择语音和语速
python simple_audiobook.py 你的小说.txt -v yunyang -r "-10%"
```

### 可用语音

| 参数值 | 语音名称 | 特点 | 适合场景 |
|--------|----------|------|----------|
| xiaoxiao | 晓晓 | 温暖女声 | 小说、故事（默认） |
| yunyang | 云扬 | 专业男声 | 新闻、知识付费 |
| yunjian | 云健 | 激情男声 | 体育、热血内容 |
| xiaobei | 晓北 | 东北方言 | 幽默、搞笑内容 |
| xiaoni | 晓妮 | 陕西方言 | 喜剧、特色内容 |

### 进阶选项

| 选项 | 说明 | 示例 |
|------|------|------|
| `-v` | 语音选择 | `-v yunyang` |
| `-r` | 语速 | `-r "+20%"` 加速，`"-10%"` 减速 |
| `--volume` | 音量 | `--volume "+10%"` |
| `--merge` | 合并章节 MP3 | 自动生成 merged/ 目录 |

## 工作流程

1. 准备文本文件（TXT 或 EPUB）
2. 运行转换命令
3. 等待生成完成
4. 在 `merged/` 目录获取最终 MP3
5. 上传喜马拉雅/小宇宙/蜻蜓FM 等平台

## 注意事项

- 首次使用需联网（edge-tts 调用微软在线服务）
- 长文本会自动按句子边界分段，每段约 2000-3000 字
- 生成的 MP3 可直接被主流音频平台接受
- 如遇网络错误，重新运行即可（已生成的片段会自动跳过）
