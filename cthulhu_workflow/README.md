## 目录结构

```
cthulhu_workflow/
├── content/          # 原始文本（放入 .txt 文件即可被处理）
├── audio/            # 生成的音频文件（按章节分目录）
├── publish/          # 发布清单（JSON格式，可追踪状态）
├── data/             # 数据追踪表 + 复盘报告
│   ├── tracker.csv   # 每日播放量/收益记录
│   └── weekly_report_*.json  # 周报
├── workflow_engine.py # 核心引擎
├── README.md          # 本文件
└── run_daily.bat      # 一键启动脚本
```

## 快速开始

### 第一步：放入内容
将文本文件（.txt）放入 `content/` 目录

### 第二步：运行工作流
```bash
python workflow_engine.py run
```

### 第三步：按清单执行发布
运行后会生成发布清单（publish/checklist_*.json），按步骤执行

### 第四步：每日记录数据
在 `data/tracker.csv` 中填入各平台数据

### 第五步：每周复盘
```bash
python workflow_engine.py review
```

## 复盘维度

1. **内容维度**：哪类故事完播率最高？
2. **时间维度**：哪个时段发布效果最好？
3. **平台维度**：哪个平台收益最高？
4. **声音维度**：哪种音色/语速最受欢迎？
5. **封面维度**：哪种封面点击率最高？
