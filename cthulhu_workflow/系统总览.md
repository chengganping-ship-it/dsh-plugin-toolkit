## 🔄 自循环工作原理

系统每**24小时**自动完成一次完整闭环：

```
02:00 ┌─────────────────────────────────────────────┐
      │ 1. 观察 — 读取所有数据、发现当前瓶颈        │
      │ 2. 假设 — 生成或选择待验证的改进假设        │
      │ 3. 进化 — 基于数据自动调整策略              │
      │ 4. 行动 — 生成优先级排序的行动清单          │
      │ 5. 执行 — 自动执行可自动化的行动            │
      │ 6. 报告 — 生成日报，保存到 data/            │
      └─────────────────────────────────────────────┘
03:00 ┌─────────────────────────────────────────────┐
      │ 自动处理下一篇文本文件 → 生成音频           │
      └─────────────────────────────────────────────┘
```

**关键洞察**（来自 Autonomous Research Agents 综述）：
> 真正的闭环 = **假设被验证后更新策略**，不是"跑指标后机械重复"。

## 🧬 系统如何自主进化

### 进化机制1：A/B测试
- 同一内容用不同标题/音色发布
- 系统记录每种变体表现
- 统计显著高的变体成为新策略

### 进化机制2：假设验证
- 发现问题 → 提出假设 → 设计实验 → 收集数据 → 验证/淘汰
- 验证通过的假设进入"已知知识库"
- 未来决策基于这些知识

### 进化机制3：策略快照
- 每次策略调整都保存完整快照
- 可以回溯到任何历史版本
- 如果新策略不如旧策略，可以回滚

### 进化机制4：进化日志
- 记录每次调整的原因、预期改善、实际改善
- 这就是AI的"决策可解释性"
- 人类可以随时审查系统为什么这样做

## ⚠️ 系统设计原则

1. **假设驱动** — 每个策略都有明确的假设支撑，不是拍脑袋
2. **数据验证** — 所有假设必须用数据验证，不能想当然
3. **可解释** — 每一次决策都有迹可循，系统不是黑盒
4. **可回滚** — 任何调整都可以回退到之前的版本
5. **知识积累** — 验证过的知识保存到"记忆库"，指导未来决策
6. **人类兜底** — 系统做80%自动化，20%关键决策需要人类审核
