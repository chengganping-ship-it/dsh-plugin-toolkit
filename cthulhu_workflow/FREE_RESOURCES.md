## 📋 推荐工作流

### 方案A：零GPU本地工作流
```
Edge-TTS(中文) → ffmpeg(合成视频) → YouTube + 喜马拉雅
+
Bing Image Creator(封面) → 588ku(背景音乐)
```

### 方案B：GPU增强工作流
```
VoxCPM 2(克隆音色) + ffmpeg(视频合成) + CosyVoice(特殊效果)
```

### 方案C：云端全自动(GitHub Actions)
```
VoxCPM 2/Speech-AI-Forge(TTS) → ffmpeg → 自动上传多平台
```
