# dsh-tool-memory

Agent Memory Management System - Memory storage, recall, compression, decay analysis, context assembly, knowledge graph building, conflict resolution, and audit reporting

## Tools

- memory_store
- memory_recall
- memory_compress
- memory_decay_analyzer
- context_assembler
- memory_graph_builder
- memory_conflict_resolver
- memory_audit_report

## Install

```bash
npm install
npm run build
```
