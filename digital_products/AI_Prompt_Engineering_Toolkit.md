## 🚀 How to Use

Each prompt follows a proven structure:
```
[CONTEXT]: Set the role and background
[TASK]: Clearly define what to produce
[CONSTRAINTS]: Specify format, length, style
[EXAMPLE]: Show expected output format (when helpful)
```

**Pro Tips:**
- Chain prompts: Use the output of one as input to the next
- Iterate: Refine prompts based on initial results
- Combine: Merge prompts from different categories for complex workflows
- Temperature: Adjust creativity level based on task (low for code/facts, high for creative)

## 💡 Sample Prompts

### 🔧 Code Generation
```
Act as a senior Python developer. Generate a {framework} API endpoint that handles {operation} for a {data_model}. 

Requirements:
- Input validation with proper error messages
- Authentication via JWT tokens
- Rate limiting (100 req/min)
- Database operations with SQLAlchemy
- Unit tests with pytest
- OpenAPI documentation

Return:
1. Complete code with type hints
2. Explanation of design decisions
3. Example curl commands to test
```

### 📝 Content Creation
```
Create a comprehensive blog post about {topic} for a {audience} audience.

Structure:
- Hook: Open with a surprising statistic or question
- Problem: Describe the pain points readers face
- Solution: Present {solution} with step-by-step guidance
- Examples: Include 2 real-world case studies
- CTA: End with actionable next steps

Tone: Professional but conversational
Length: 1500-2000 words
SEO: Target keyword "{primary_keyword}", include 3 related terms
```

### 📊 Data Analysis
```
You are a data scientist analyzing a dataset about {domain}.

Dataset description: {schema_description}

Perform the following analysis:
1. Data quality assessment (missing values, outliers, types)
2. Descriptive statistics with visualizations
3. Correlation analysis between key variables
4. Trend identification and seasonality detection
5. Predictive modeling preparation (feature engineering)
6. Executive summary with actionable insights

Output format:
- Python code with pandas, matplotlib, seaborn
- Markdown narrative explaining findings
- 3 key business recommendations
```

### 🎯 Business Strategy
```
Conduct a comprehensive market analysis for {product/service} targeting {market}.

Include:
1. TAM/SAM/SOM calculation with methodology
2. Top 5 competitors with SWOT analysis
3. Pricing strategy comparison (freemium, tiered, usage-based)
4. Go-to-market timeline (first 90 days)
5. Key metrics and KPIs to track
6. Risk assessment with mitigation strategies

Format: Professional consulting report
Audience: C-level executives
Length: 2000-2500 words
```

### 🤖 AI Agent System Prompt
```
You are {agent_name}, an autonomous AI agent specializing in {domain}.

## Core Capabilities
- {capability_1}
- {capability_2}  
- {capability_3}

## Operating Principles
1. Always verify information before acting
2. Break complex tasks into manageable subtasks
3. Provide progress updates every 3-5 steps
4. Ask for clarification when requirements are ambiguous
5. Prioritize safety and ethical considerations

## Tool Usage
- Search: Use for fact-checking and current information
- Code: Execute scripts for data processing and automation
- Files: Read/write for persistent storage and documentation

## Error Handling
- On tool failure: Retry once, then escalate
- On ambiguous input: Ask clarifying questions
- On ethical concerns: Refuse and explain reasoning

## Output Format
- Structured reports with clear sections
- Code with comments and documentation
- Decisions with rationale
- Next steps always included
```
