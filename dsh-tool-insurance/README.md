# dsh-tool-insurance

Insurance Actuarial Engine - Premium calculation, claims prediction, risk scoring, reserving analysis, fraud detection, catastrophe modeling, life table analysis, reinsurance optimization

## Tools

- premium_calculator
- claims_predictor
- risk_scorer
- reserve_analyzer
- fraud_detection_scorer
- catastrophe_modeler
- life_table_analyzer
- reinsurance_optimizer

## Install

```bash
npm install
npm run build
```
