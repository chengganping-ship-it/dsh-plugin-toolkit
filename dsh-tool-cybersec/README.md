# dsh-tool-cybersec

Cybersecurity Threat Intelligence - Threat intel analysis, vulnerability scanning, attack surface mapping, security posture scoring, incident classification, phishing detection, firewall rule auditing, compliance mapping

## Tools

- threat_intel_analyzer
- vulnerability_scanner
- attack_surface_mapper
- security_posture_scorer
- incident_classifier
- phishing_detector
- firewall_rule_auditor
- compliance_mapper

## Install

```bash
npm install
npm run build
```
