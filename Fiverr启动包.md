## 十、交付 SOP（接到单后照做，三步 AI + 人工审核）

> 核心：不是"AI 改一遍就交"，是"ATS分析 → 改写 → 质检"三步，每单 20-40 分钟。

```
【Step 1 · ATS Gap 分析】
把买家简历 + 目标JD丢给 AI，用 ATS Gap Prompt：
  - 提取JD前15个关键词
  - 做匹配表（Present / Weak / Missing + 简历证据 + 改进建议）
  - 给出Top5改写优先级

【Step 2 · 改写】
用 Rewrite Prompt，把简历 bullets 针对该JD改写：
  - Action verb + 任务/场景 + 工具/技能 + 结果
  - 缺失数据用 [ADD METRIC IF TRUE]，绝不编造

【Step 3 · AI质检 + 人工过一遍】
用 QA Prompt 严格审计：有没有编造经历/虚假数据/夸大/漏JD关键词/ATS格式风险/语法。
人工最后通读一遍，重点核对"没编造"。

【交付】
存成 PDF，通过 Fiverr 私信交付，附说明："已针对 [岗位] 定向优化，ATS匹配表见附件，重点改了XXX，有问题随时改"。
等确认后礼貌请求好评。
```

### ATS Gap Prompt（Step 1 用）
```
You are an ATS resume analyst.
Compare the resume against the target job description.
Rules:
- Do not invent experience, employers, tools, metrics, degrees, or certifications.
- Mark missing information as [NEEDS USER INPUT].
- Separate hard skills, tools, responsibilities, and soft skills.
- Identify keywords as clearly present, weakly present, or missing.
Output:
1. Top 15 target keywords from the JD
2. Resume match table: Keyword | Present/Weak/Missing | Resume evidence | Suggested improvement
3. Top 5 rewrite priorities
```

### QA Prompt（Step 3 用）
```
Act as a strict resume quality auditor.
Check the rewritten resume for:
1. Any invented experience
2. Any unsupported metrics
3. Any exaggerated claims
4. Missing JD keywords
5. Weak bullet points
6. ATS formatting risks
7. Grammar or clarity issues
Return: Pass/Needs Fix, specific fixes, final revised version.
```
